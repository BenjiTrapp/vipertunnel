01Every connection, on one axis

One lane per implant host. A bar is a command connection, amber ticks inside it are keep-alives, red marks are deaths, and the band underneath is a relay session carrying traffic. A gap is labelled only where the rhythm changes — so a run with one label is a run with one cadence.

command connection keep-alive relay session channel died

Nothing has connected yet. Start the client against this server: the first command connection appears here as a bar. One that keeps growing is the held shape; bars that repeat are the cadence.

  // provenance of these numbers
  
    Every value on this page is derived from events that were written to the
  ledger file as well; the file stays the artefact a finding cites. The
  cadence is the mean, standard deviation and coefficient of variation over
  the gaps between client-connected events from one host — the
  arithmetic a beaconing detection runs. Fewer than two gaps is not a
  cadence and is reported as such rather than as a mean over one number.
    
  
    This view is out of band: a listening HTTP port is a trait this
  family does not have, so a scan of this host taken with the dashboard up
  reports the tool rather than the thing being emulated. It binds loopback
  only; reach it over an SSH forward. Fonts are served from this server, not
  a CDN — see server/web/fonts/README.md.
